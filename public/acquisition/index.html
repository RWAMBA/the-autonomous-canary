What to include

Do not submit source code, credentials, secrets, or production logs. We only need business contact details, an optional repository name, and a concise description of the release challenge.

Each lead receives a 180-day retention deadline unless an engagement begins or law requires otherwise.
Repository identity Optional

Use the exact GitHub owner and repository name. Spaces are not permitted; leave both fields blank if no repository applies.
